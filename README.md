# Technology Outreach Foundation — Official Website

The public website and e-commerce platform for Technology Outreach Foundation
(TOF), a nonprofit expanding STEM access for underrepresented students through
laptop distribution, ACT tutoring, college admissions prep, and a Leadership
Outreach Series.

## About TOF
Founded in 2024, TOF serves students with technology access and academic
support programs designed to close the STEM opportunity gap.

## What's in this repo
- **Public site** — replaces a prior Google Sites presence, eliminating 100%
  of recurring hosting/domain costs
- **Merchandise store** — full-stack e-commerce feature for purchasing TOF
  merch, with Stripe integration for payments and webhook-driven order tracking
- **Backend services** — support fundraising and merchandise sales

## Tech Stack
- Frontend: HTML5, CSS, JavaScript
- Backend: Node.js, Express.js
- Database: MySQL
- Payments: Stripe API + webhooks
- Hosting: Render

## Status
🚧 Active development — migrating to Next.js/TypeScript/Tailwind/shadcn as
part of a broader site redesign.
